## 🛠️ Stack Tecnológico y Entorno

- **Lenguaje:** Java 17 LTS / OpenJDK 17
- **Framework:** Spring Boot 3.x
- **Gestión de Versiones:** Git & GitHub Flow
- **Control de Tareas:** GitHub Projects (Kanban Board de 4 Estados)
- **Calidad y Commits:** Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`)

## 📌 Guía de Inicio Rápido

### 1. Clonar el repositorio
```bash
git clone https://github.com/edwinsiguas/Semana10.git
cd Semana10
```

### 2. Convención de Ramas
- Rama principal de producción: `main`
- Ramas de características: `feature/issue-<id>-<descripcion-corta>`
- Ramas de corrección: `bugfix/issue-<id>-<descripcion-corta>`

### 3. Reglas de Trabajo en Equipo
1. Ningún desarrollador puede tener más de **2 tareas simultáneas en estado "En proceso"** (Límite WIP).
2. Todo avance debe contar con su Issue asociado, Criterios de Aceptación verificados y evidencia técnica adjunta en el Pull Request.
